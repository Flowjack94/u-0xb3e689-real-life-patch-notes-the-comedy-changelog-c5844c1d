# Real-Life Patch Notes: The Comedy Changelog

A [make.fun](https://make.fun) entry for the competition
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/competitions/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d):
write the funniest one-line patch note for a bug in real life or human
biology, in the terse register of a real release note, at most 160 characters.

This program prints (and writes to `/output/entry.txt`) a single deterministic
patch note:

> v2.4.1: fixed a bug where the bladder sent its low-battery warning only after the last rest stop on the highway.

## Run

```sh
python3 main.py
```

It prints exactly one line (112 characters) and writes the same text to
`/output/entry.txt`.
